# 钢铁战线 / Steel Front V2.2

现代战争 RTS 独立浏览器原型；基于 V2.1 增量开发，保留既有 14 兵种、地空寻路层、经济和生产系统。无第三方运行依赖。

## 游戏方式
将 index.html 保存到本地并使用现代浏览器打开，或放在静态 HTTP 服务器。默认暂停。选择规模（24/200/500/1000），新战局，开始。单击选中一个友军、拖动框选；右键或点击空地图移动。选择单位后，通过右侧据点的「调遣」按钮下令。Ctrl+数字保存控制组，数字召回，Esc 清空。空格控制暂停；支持 1/2/4 倍速，性能不足时自动有实时时间偏差（不会无限补算）。

## 领土规则
- 5 个据点，初始中立，半径 67 像素。仅活着的地面单位可占领；双方地面单位在圈内时暂停进度、资源和积分。空圈保留当前进度和所属。
- 进度 -1 对应友军，+1 对应敌军；反向争领须先经过中立。旧领主在进度达中立前仍享有收益（双方在场争夺时除外）。人数影响占领速度，最高每秒 1.7 进度。
- 未争夺的已占领据点每秒为所属阵营提供 8 资源、1 胜利分。达到 240 积分或摧毁敌 HQ 胜利；同一 tick 双总部摧毁为平局；同 tick 两种胜利条件相遇时 HQ 优先。双方同 tick 满分时较高积分胜，完全相等为平局。
- 据点控制信息为双方公开；战斗保留原有单位视野和雾层。现有战场统计和 AI 空军计数并非严格隐藏信息。
- AI 使用三支固定分组占领东北、东南及中央据点；三处稳定控制后中央分组进攻西侧点。新兵自动加入，玩家指令与 AI 指令独立排队。AI 为规则型而非学习型，尚无完整动态兵力调配、专用补给调度或三阵营逻辑。

## 测试
`npm test` 运行 9 项旧回归 + 11 项新增测试（无需 npm install，只需 Node）。`npm run test:long` 运行四档场景。浏览器测试需要 Python playwright 和 Chromium，环境路径见测试脚本。当前浏览器测试以 set_content 注入实际 HTML 运行（容器禁止本地 file URL），未验证用户设备上的系统级文件访问。

## 文件
- `index.html` 单文件可玩原型，内含仿真与界面。
- `tests/` 测试脚本。
- `artifacts/` 实际测试日志及截图。
- `docs/` 技术说明、变更与验收；历史文档保留在 history/。

不代表商业级成品；1000 单位仅短时验证，AI 对抗平衡、实体建筑阻挡、完整视野公平性、移动端全流程和长期稳定性尚待确认。
