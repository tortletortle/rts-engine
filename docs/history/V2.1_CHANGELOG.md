# 更新记录

## V2.1

### 新增
- 增加 24 / 200 / 500 / 1000 单位规模选项。
- 14 种兵种加入独立移动速度数据。
- 空军使用独立飞行寻路层，可跨越地面障碍并与地面单位共享平面坐标。
- 空地单位碰撞审计按移动层区分。
- 增加空军基地生产路径；AI 能生产武装直升机并根据敌方空军数量响应防空。
- 增加选中单位的类型、移动层与速度显示。

### 性能与稳定性
- 战斗目标与视野查询改为阵营分桶的空间哈希索引。
- 大规模战场降低小地图、战争迷雾和诊断统计刷新频率。
- 千单位初始部署调整到双方基地附近，不再从地图上边缘出生。
- 1000 单位持续模拟 100 步，碰撞审计为 0。

### 已知限制
- 仍为双阵营；资源点占领、完整科技树、完整战争迷雾、网络联机和地图编辑器未实现。
