# 钢铁战线（Steel Front）V2.1

现代战争即时战略游戏原型。当前版本重点完成大规模战场基础、空地分层移动和战斗查询优化。

## 启动

无需安装依赖或构建工具：

1. 解压项目包。
2. 使用 Chrome 或 Edge 打开 `index.html`。
3. 在右上角选择战场规模，点击“新战局”应用。

可选：也可以在项目目录运行 `python -m http.server 8000`，然后访问 `http://localhost:8000`。

## 当前功能

- 14 种单位：轻/主/重型坦克、反坦克导弹车、机械化步兵、自行火炮、侦察车、维修车、火箭炮、武装直升机、防空导弹车、无人侦察机、电子战车、后勤补给车。
- 兵种克制与弹药限制；维修、补给、电子干扰等辅助单位行为。
- 空军与地面部队使用独立寻路层；空中单位可以越过地面障碍，也不与地面单位争抢移动格。
- 兵种差异化移动速度，速度以 px/s 定义。
- 24、200、500、1000 单位战场规模；1000 模式为双方各 500 个初始单位。
- 资源收入、基地建筑、兵种生产、科技升级。
- 小地图、战争迷雾、编队目标槽、控制组快捷键。
- 基础 AI 经济扩张、兵种生产、空军生产与防空响应。
- 大规模战斗使用按阵营分桶的空间哈希索引，缩小视野与目标查询范围。

## 操作

- 鼠标左键拖动：框选己方单位。
- 鼠标右键：向选中单位下达移动指令。
- `Ctrl + 1–9`：保存控制组。
- `1–9`：召回控制组。
- `Space`：暂停/继续。
- “单步”：推进一次模拟步。
- 战场规模切换后需要点击“新战局”。

## 测试

需要 Node.js 22 或兼容版本：

```bash
npm test
```

或：

```bash
node tests/test_v21.cjs
```

浏览器验收脚本是可选项，需要 Python、Playwright 和 Chromium：

```bash
python tests/browser_acceptance.py
```

## V2.1 验收摘要

- Node 自动化：9/9 项通过。
- 1000 单位持续模拟：运行 100 个模拟步（5 秒游戏时间），1000 个单位存活，碰撞审计为 0；AI 已执行移动指令。
- 1000 单位空间战斗查询：100 步累计候选检查约 356 万次，避免每步对所有单位进行全量两两扫描。
- Chromium 浏览器验收：1000 单位模式约 32 FPS（本次无头测试环境），碰撞审计为 0；框选、右键移动、暂停和单步操作通过；未发现页面 JavaScript 异常。

测试数据是本次固定地图与测试环境下的结果，不代表任意地图、任意硬件或所有战局都能达到相同帧率。

## 当前明确未完成

- 目前只有两个阵营，三阵营尚未实现。
- 资源点争夺/占领机制尚未实现；当前资源主要来自基地矿站与基础收入。
- 地图仍是固定测试地图，地形和障碍物表现较简化。
- AI 仍属于基础策略，不具备完整战役级决策、侦察情报和多线协同能力。
- 战争迷雾目前以单位视野圆形区域近似实现，不是完整视线遮挡系统。
- 尚未实现网络联机、回放、地图编辑器和完整科技树。

V2.1 是可运行、可测试的研发原型，不应被描述为已经完成的商业级 RTS。
